# Portfolio Image Placement Guide

This guide details exactly where to place all images and what to name them for your portfolio projects. All images should be placed in the `public/img/projects/` directory.

## General Guidelines

### Image Specifications
- **Thumbnails:** 800x600px minimum, 16:9 or 4:3 aspect ratio
- **Detail Images:** 1200x800px minimum for good quality
- **File Format:** JPG for photos, PNG for graphics with transparency
- **File Size:** Optimize images (compress) to keep under 500KB each
- **Naming:** Use lowercase, hyphenated names (no spaces)

### Logo Usage
- **If a project has a logo, USE IT as the thumbnail/cover image**
- Place logos prominently as the first image in the project detail page
- For projects without logos, use the most representative design piece

### Process vs Final
- Include both process work and final outcomes
- Process images should show: research, wireframes, iterations
- Final images should show: completed designs, mockups, implementations

### Special Files
- **PDFs:** Place any PDFs you want to link in the project folders
- **Videos:** Use YouTube embeds (already implemented for some projects)
- **Prototypes:** Use Figma embed links (already implemented)

## Next Steps
1. Create all the folders listed above in `public/img/projects/`
2. Add your images with the exact file names specified
3. If you have logos for projects, make sure to use them as covers
4. Optimize all images for web (compress file sizes)
5. Test that all projects load correctly on your portfolio

## Notes
- The portfolio will automatically pick up images with these exact names
- If you don't have certain images, create placeholder images or remove those image references from the code
- Always use the logo as the cover/thumbnail if available
- Process images help show your design thinking and methodology
